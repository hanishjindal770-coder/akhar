Guide

Raavi vs Asees font

If you learned Punjabi typing a few years ago, you may have learned on Asees, AnmolLipi or a similar font. Punjab typing tests now usually ask for Raavi. The two are not just different looks: they work in completely different ways, and so do their keyboards.

Legacy fonts: Asees, AnmolLipi, Joy and others

Legacy Punjabi fonts were made before Unicode was common. They take the codes of ordinary English letters and draw Gurmukhi shapes in their place. When you type in Asees you are really typing English characters that only look like Punjabi because of the font.

  • If the reader's computer does not have the same font, the text shows up as English letters and symbols.
  • Search engines, spell checkers and copy-paste into other programs see the English letters, not Punjabi.
  • Each legacy font family can have its own key layout, so skills do not always carry from one to another.

Unicode fonts: Raavi

Raavi is a Unicode font. Every Gurmukhi letter has its own standard code, the same on every computer and phone. Any Unicode Gurmukhi font can display the text, and it can be searched, sorted and copied anywhere. That is why government offices have moved to Unicode for official work.

On Windows, Unicode Punjabi is typed with the built-in Punjabi keyboard, which uses the INSCRIPT layout. INSCRIPT is a standard layout for Indian scripts: vowel signs on the left hand and consonants on the right. See the full layout chart.

Which one should you learn?

Learn the font your recruitment notice names. For most current Punjab government typing tests that is Raavi with the INSCRIPT keyboard, but read your own notice, because a few older or departmental tests have used other fonts.

Switching from Asees to Raavi

Your touch typing skills carry over: posture, finger positions, reading ahead and rhythm all stay the same. What changes is where each letter lives. Expect your speed to drop for the first two or three weeks while your fingers relearn the keys.

  • Start with the Akhar lessons from stage one, even if it feels basic. They introduce the INSCRIPT keys in small groups.
  • Do not practise Asees at the same time; switching back and forth slows down the new habits.
  • Once you know all the keys, check your speed with the Raavi font typing test.

Why Unicode matters for your future job

A clerk or data entry operator types letters, notices and records that other offices read and search. Text typed in a legacy font can turn into meaningless English letters when it is emailed, uploaded to a website or opened on another computer. Unicode text stays correct everywhere, which is why Unicode Punjabi is now used for official work and online portals. Learning Raavi with INSCRIPT is useful long after the typing test.

Can you convert old Asees text to Unicode?

Yes. Several free converters take text typed in Asees, AnmolLipi or similar fonts and change it to Unicode. Results are usually good but not perfect, so read through the converted text. Converters only change existing text; they do not change how you type, so you still need to learn the INSCRIPT layout for the test.

Common questions

Is Raavi the only Unicode Punjabi font?

No. Nirmala UI, Noto Sans Gurmukhi, Mukta Mahee and others are also Unicode. They all use the same codes, so text typed with any of them can be shown in Raavi. The keyboard layout is the same INSCRIPT layout whichever Unicode font you use.

Will my speed on Asees carry over?

Your general typing skill will, but your key memory will not. Expect to start slower and catch up within a few weeks of daily practice.

Do I need to install Raavi?

Not on Windows, where it is already installed. On other systems you can type Unicode Punjabi with whatever Gurmukhi font is available, and it will still be correct Unicode text. For practice on Akhar you do not need Raavi at all: the site shows Punjabi in Raavi if your computer has it, and in a matching Unicode font if it does not.

Is INSCRIPT the same as the "phonetic" Punjabi keyboard?

No. Phonetic or transliteration keyboards let you type Punjabi using English sounds, such as typing "k" for ਕ and having the software guess the word. INSCRIPT is a fixed layout where each key always gives the same character. Typing tests use INSCRIPT, so practise on that.
